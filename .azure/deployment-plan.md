# EASM 배포·정리 기록

- Status: Validated - demo teardown approved
- 배포 방식: Azure CLI + 기존 Bicep.
- 환경 입력: `.wasm-agent/setup.json`, `config/lab.yaml`.
- 승인 범위
  - 소유 태그가 확인된 별도 데모 리소스 그룹.
  - Korea Central·소형 모델·승인된 검증 예산.
  - 관리자 배포·일회성 인증 준비와 진단 SP 읽기 수집을 분리.
  - 진단 SP의 Owner/Contributor/User Access Administrator 사용 금지.
- 재배포
  - 배포 전 테스트·Ruff·Bicep·ARM validate/what-if·정책 조회를 실행.
  - `.azure/validation.json`의 passed=true 확인 후 `--apply`로 실행.
  - 삭제된 Foundry 계정의 soft-delete 보존과 재생성을 혼동하지 않도록 새 generation 사용.
  - 상세 명령은 [README](../README.md)의 접힌 배포 전용 안내와 [데모 운영](../docs/demo.md) 참고.
- 검증 기록
  - 새 Agent 10개·실제 평가 4건·웹 대화·진단 SP 수집 확인.
  - Codespaces 실제 수집·XLSX 체크리스트·증거 링크·ZIP 무결성 확인.
  - 개인키 정리·진단 앱 공개 인증서 0건 재조회.
  - 비용 미반영·범위 밖 중앙 로그·AI 보안 기능 자료 부족은 판정 보류로 보존.
- 이번 파일 정리
  - 사용자 출력은 `report.html`·`report.xlsx`·`results.zip` 세 개.
  - ZIP의 `data.json`에 정규화 데이터·마스킹 증적·출처를 통합.
  - 문서는 고객 안내·개발 참고·데모 운영으로 통합.
  - 재배포용 설정과 관리자 상태는 `.wasm-agent/`에 분리.
- 이번 삭제 승인
  - 현재 소유 태그가 확인된 데모 리소스 그룹만 삭제.
  - 진단 계정·역할·로그인 앱 등록·Codespaces는 유지.
  - 삭제 후 그룹 부재를 재조회하고 `.wasm-agent/demo/cleanup.json`에 기록.
  - 이번에는 다시 배포하지 않음.
- API·역할 근거: [개발 참고](../docs/api-notes.md).
